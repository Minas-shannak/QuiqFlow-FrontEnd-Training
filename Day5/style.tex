Project Overview:

Fetch data from an API and display it in a dynamic grid layout.

Implement selection logic with background color updates.

Include "Select All" and "Deselect All" functionality.

Key Deliverables:

DOM manipulation, event handling, and real-time UI updates using JavaScript.

Task Details:
1️⃣ Fetch data from the API:

Use fetch() to call the endpoint Magic The Gathering API.

Parse and store the response, then display it dynamically.

2️⃣ Create a grid layout using JavaScript (no CSS files).

Display each item as a card containing: title, description, and a "Select" button.

Use CSS Grid (through JavaScript) to create a responsive layout.

3️⃣ Implement the "Select" button:

Toggle background color and update the selection counter when clicked.

Implement "Select All" and "Deselect All" buttons to control selection.

4️⃣ Follow JavaScript best practices:

DOM manipulation, event listeners, and dynamic styling.
